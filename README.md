## 📝 更新履歴 (Changelog)

### v1.0.0 - 初回公開リリース
**基本モデリング機能**
- キューブの追加・複製・名前変更・削除
- サイズ（Size）・位置（Position）・回転（Rotation）のスライダー＆数値直接入力
- スライダー刻み幅の切り替え（`1` / `0.5` / `0.1` 刻み自動吸着）

**ボーン＆アニメーション**
- 複数ボーンの作成・親子階層化（Parent設定）・関節支点（Pivot）の3Dマーカー表示
- 4Dスキン用プレイヤー基本ボーン＆素体テンプレートのワンタップ読込
- 「アニメ」タブでのボーン単体回転テスト ＆ 歩行モーション自動プレビュー再生

**ペイント＆テクスチャ機能**
- 3種類のペイントモードに対応（3Dモデルに直接ペイント / 面ごとペイント / UV展開図全体ペイント）
- 描画ツール一式（ペン・バケツ塗りつぶし・直線・円・長押しスポイト・消しゴム・太さ1〜4px）
- 解像度切り替え（8×8 / 16×16 / 32×32 / 64×64）＆ 既存画像ファイル読込

**データ保存＆Minecraft BE 入出力**
- Web内保存（最大10スロットまで名前付き保存・上書き・読込・削除）＆ 3秒ごとの自動バックアップ
- 独自プロジェクトファイル（`.mcbe3d`）の保存・読み込み
- 既存の Minecraft BE モデル（`.geo.json`）のインポート対応
- Minecraft BE 用 `.geo.json` ＆ `.png` テクスチャの書き出し

**マルチデバイス対応**
- スマホ（iPhone / Android）のタッチ操作（1本指・2本指）対応
- PC（Windows / Mac）のマウス操作＆ワイド画面向け左右2分割レイアウト自動切替
